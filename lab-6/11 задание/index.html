HTML — это язык разметки, который используется для создания структуры веб-страниц.

CSS — это язык стилей, который отвечает за оформление и внешний вид веб-страницы.

JavaScript — это язык программирования, который добавляет интерактивность веб-страницам.

DOM — это объектная модель документа, позволяющая JavaScript изменять HTML-элементы страницы.
